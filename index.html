Conversor de legendas para o YouTube

Arraste uma legenda .srt, .sbv ou .ass e baixe o .ytt pronto para enviar ao YouTube. Tudo acontece no seu navegador: o arquivo não é enviado para lugar nenhum.

    Abra esta página por um servidor (por exemplo o GitHub Pages); abrindo o arquivo direto do disco o navegador bloqueia os módulos JavaScript.
