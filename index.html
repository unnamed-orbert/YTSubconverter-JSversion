Conversor de legendas para o YouTube

Arraste uma legenda .srt, .sbv, .ass ou .json3 (o formato que o YouTube serve) e baixe o .ytt pronto para enviar ao YouTube, ou solte um .ytt para ver como ele fica. O formato é reconhecido pelo conteúdo, então o arquivo pode vir sem extensão ou com a extensão errada. Tudo acontece no seu navegador: o arquivo não é enviado para lugar nenhum.
